유전자 발현 데이터에서 예후 관련 특성을 찾고 외부 데이터로 검증한 분석 프로젝트

다발성 골수종 예후 예측 데이터 분석 Bio-AI Data Analysis

기간
2025.11 (데이터 분석 프로젝트)
데이터
GSE24080, GSE19784
역할
유전체 데이터 전처리, 특징 선별 및 예후 예측 모델링
기술
Python, XGBoost, Random Forest, Logistic Regression, ANOVA, RFE, SHAP, NCBI GEO

주요 구현

  • NCBI GEO의 GSE24080에서 환자 559명의 약 23,500개 유전자 발현 정보와 생존 정보 정제
  • ANOVA, RFE(Recursive Feature Elimination), 모델 중요도를 활용해 고차원 유전자 특성 선별
  • Logistic Regression, Random Forest, XGBoost를 AUC, MCC, F1 등으로 비교해 최종 모델 선정
  • SHAP으로 모델 예측에 크게 기여한 유전자 확인
  • Risk score로 환자를 위험도별로 나누고 독립 데이터셋 GSE19784에서 외부 검증
  • 바이오 산업 실무자, 박사급 전문가에게 분석 과정과 생물학적 해석을 검토받음

Problem

  • ISS, R-ISS 같은 기존 병기 체계만으로는 고위험 환자를 초기에 가려내기 어려움
  • 환자 수에 비해 유전자 특성이 약 23,500개로 매우 많아 생존과 관련된 특성을 골라내야 함

Solution

  • ANOVA, RFE, 모델 중요도를 차례로 적용해 분석에 쓸 유전자 수를 줄임
  • 세 모델을 여러 지표로 비교한 뒤 SHAP과 risk score로 결과를 해석하고 GSE19784로 외부 검증

Impact

  • 단계적 특성 선별과 SHAP 분석으로 예후 biomarker 후보 10개 도출
  • Risk score를 10개 구간으로 나눴을 때 점수가 높을수록 사망률도 높게 나타남 (Spearman ρ=0.888, p<0.001)
  • GSE24080으로 학습한 모델을 별도 데이터셋 GSE19784에 적용해 외부 검증
